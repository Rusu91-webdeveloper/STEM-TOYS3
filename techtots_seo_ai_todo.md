# 📝 SEO + AI Discoverability To-Do List for www.techtots.ro

This roadmap will help Techtots rank for **STEM toys** on Google and AI search platforms in 2025.

---

## 1️⃣ Setup & Monitoring
- [ ] **Set up Google Search Console** → [https://search.google.com/search-console](https://search.google.com/search-console)  
- [ ] **Set up Google Analytics GA4** → [https://analytics.google.com/](https://analytics.google.com/)  
- [ ] **Set up Bing Webmaster Tools** → [https://www.bing.com/webmasters/](https://www.bing.com/webmasters/)  
- [ ] **Verify site speed & vitals** → [https://pagespeed.web.dev/](https://pagespeed.web.dev/)  
- [ ] **Monitor backlinks & keywords** → [https://ahrefs.com/](https://ahrefs.com/) or free [https://neilpatel.com/ubersuggest/](https://neilpatel.com/ubersuggest/)  

---

## 2️⃣ On-Page SEO
- [ ] Add **unique title tags** for each page.  
- [ ] Add **meta descriptions** (≤160 chars).  
- [ ] Use proper **headings (`<h1>`, `<h2>`)**.  
- [ ] Add **alt text** to every product image.  
- [ ] Clean, keyword-rich **URLs** (e.g. `/stem-toys/robotics-kit`).  

---

## 3️⃣ Structured Data (Schema Markup)
- [ ] Add **Product Schema** (price, availability, reviews).  
- [ ] Add **Breadcrumb Schema**.  
- [ ] Add **FAQ Schema**.  
- [ ] Add **Organization Schema**.  
👉 Generator: [https://technicalseo.com/tools/schema-markup-generator/](https://technicalseo.com/tools/schema-markup-generator/)  

---

## 4️⃣ Content Strategy (Google + AI Assistants)
- [ ] Create **pillar page**: “Best STEM Toys in 2025”.  
- [ ] Write **educational blogs**.  
- [ ] Add **FAQ page**.  
- [ ] Translate/localize with **hreflang tags**.  
👉 Keyword research: [https://neilpatel.com/ubersuggest/](https://neilpatel.com/ubersuggest/)  

---

## 5️⃣ Technical SEO
- [ ] Generate **XML Sitemap** → [https://www.xml-sitemaps.com/](https://www.xml-sitemaps.com/)  
- [ ] Ensure **robots.txt** allows crawling.  
- [ ] Optimize **Core Web Vitals**.  
- [ ] Use **Next.js `<Image>`** for WebP/AVIF.  
- [ ] Deploy with **CDN (Vercel/Cloudflare)**.  

---

## 6️⃣ AI Optimization (ChatGPT, Perplexity, Google SGE)
- [ ] Publish **clear, concise product descriptions**.  
- [ ] Use **FAQ + HowTo schema**.  
- [ ] Build **author pages** with expertise.  
- [ ] Submit content to **Perplexity AI Publisher** → [https://www.perplexity.ai/publisher](https://www.perplexity.ai/publisher)  
- [ ] Gain **citations on trusted sites**.  

---

## 7️⃣ Growth & Authority
- [ ] Claim & optimize **Google Business Profile** → [https://www.google.com/business/](https://www.google.com/business/)  
- [ ] Get **backlinks** from blogs & STEM sites.  
- [ ] Run **press releases**.  
- [ ] Collect **reviews/testimonials**.  
- [ ] Build **social proof** on Instagram, TikTok, Facebook.  

---

✅ Consistently working through this list will boost **SEO authority + AI discoverability**, ensuring Techtots shows up for **STEM toys searches** in Romania and beyond.
