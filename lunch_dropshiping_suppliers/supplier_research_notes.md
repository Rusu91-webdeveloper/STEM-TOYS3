# European STEM Toy Dropshipping Suppliers Research

## 1. BigBuy (Spain)
- **Focus:** General wholesaler with a strong "Learning and Education" section.
- **Integration:** RESTful API (JSON), CSV/XML feeds.
- **Technical:** Full API for catalog, orders, shipping costs, and tracking. Ideal for Next.js.
- **Logistics:** Ships from Spain to Romania. Fast delivery across Europe.
- **Pros:** Professional API, massive catalog, multi-language support.

## 2. Hertwill (Estonia/EU)
- **Focus:** High-quality European and US brands.
- **Integration:** Primarily Shopify/WooCommerce apps, but mentions "Import List" and potential for manual/custom use.
- **Logistics:** Ships from European warehouses. 3-8 business days delivery.
- **Pros:** Curated high-quality brands, handles returns and warranties.

## 3. LeanToys (Poland)
- **Focus:** Specialized toy wholesaler.
- **Integration:** XML/CSV feeds (IOF 3.0, 2.6, 2.5). API available for IdoSell platform (might need custom work for Next.js).
- **Logistics:** Ships from Poland. Good proximity to Romania.
- **Pros:** Specialized in toys, competitive pricing, proximity to Romania.
- **Cons:** Activation fee for feeds (€50).

## 4. TWM (TOM-Group, Netherlands)
- **Focus:** Massive catalog (350k+ items).
- **Integration:** CSV/XML feeds, API available.
- **Logistics:** Ships to 26 European countries including Romania.
- **Status:** Currently NOT accepting new dropshipping partners (as of Jan 2026).

## 5. Ikonka (Poland)
- **Focus:** Toys and general merchandise.
- **Integration:** XML generator, various platform integrations (Baselinker, etc.).
- **Logistics:** Ships from Poland.
- **Pros:** Strong integration support for Polish/European platforms.

## 6. Syncee (Marketplace)
- **Focus:** Marketplace connecting retailers with suppliers.
- **Integration:** DataFeed Manager (CSV, XML, JSON). API for custom integrations.
- **Pros:** Access to multiple European STEM toy suppliers in one place.
